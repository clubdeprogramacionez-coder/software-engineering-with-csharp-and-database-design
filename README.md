# School Management Learning Lab

Curso de Ingeniería de Software orientado al desarrollo de un Sistema de Gestión Escolar utilizando C# y SQL Server.

## Instructores

Curso de Ingeniería de Software - ESIME Zacatenco (IPN).

## Objetivo del Curso

Comprender el ciclo de vida del desarrollo de software (SDLC) y aplicarlo en la construcción de una aplicación completa de gestión escolar. Aprender análisis, diseño, arquitectura de bases de datos, programación orientada a objetos con C# y Entity Framework Core.

## Módulos del Curso

- **docs/requerimientos/**: Especificaciones y requisitos del sistema.
- **docs/uml/**: Diagramas UML, casos de uso, clases y secuencias.
- **docs/base-datos/**: Diseño de base de datos, modelos ER y documentación SQL.
- **src/**: Código fuente de la solución Visual Studio con proyectos C#.
- **database/scripts/**: Scripts SQL, migraciones y estructura de base de datos.

## 🛠 Requisitos y Herramientas

Para desarrollar y ejecutar el proyecto necesitarás:

- **Lenguaje**: C# 12.0+
- **Framework**: .NET 8.0
- **IDE**: Visual Studio 2022+
- **ORM**: Entity Framework Core 8.0+
- **Base de Datos**: SQL Server 2019+
- **Control de Versiones**: Git y GitHub
